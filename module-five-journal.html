Technologies I Chose

I chose generative AI for software development and extended reality (XR), which includes virtual reality and augmented reality. Both are game changers because they change how software is created or how people interact with it. They also connect to the software and games I want to build.

Identification and Description of Each Technology

Generative AI creates content, including code, from prompts and context. AI coding tools can suggest implementations, explain existing code, and assist with reviews. GitHub Copilot is one example (GitHub, n.d.). This breaks the older pattern in which developers manually wrote most implementation details and creates a trend toward AI-assisted development. Developers still need to decide whether the output is correct and suitable.

XR combines immersive virtual environments with digital content placed in the physical world. VR replaces the view with a simulated environment, while AR adds digital objects to the real one. XR breaks the screen-and-mouse interaction pattern by using spatial views and tracked movement. It has encouraged immersive games, simulations, and shared environments. OpenXR provides a common API across XR devices, reducing the need for separate device-specific integrations (Khronos Group, n.d.).

Likely Impacts on Computer Science

AI-assisted development changes the industry workflow by making code generation and automated review part of everyday development. I expect more attention to requirements, architecture, testing, and security as developers evaluate generated changes. Faster first drafts can help, but incorrect output creates extra review work. The tests I wrote for Clearspace show why checking behavior matters regardless of how code is produced.

XR increases the need for real-time graphics, spatial input, accessible interaction, and efficient networking. Developers must balance image quality with frame time and user comfort. Shared APIs can make applications easier to move between devices. My work on Clearspace performance has given me practice with responsiveness and resource tradeoffs, although immersive applications would require additional graphics and interaction skills.

Impacts on Humans Communities and the World

AI coding tools could help individuals and small teams build useful software sooner and make programming easier to approach. Communities could benefit from tools tailored to local needs. However, mistakes, biased output, and insecure code can affect many users when software is distributed. Workers may spend more time reviewing automated work, and people entering the field will still need opportunities to build their own problem-solving skills.

XR could support remote social interaction, immersive education, and training where practicing in the real world is expensive or dangerous. These uses may connect people across distance and give communities new ways to share experiences. Hardware cost, motion sickness, and accessibility barriers can exclude users. Tracking data and harassment in shared environments also require careful privacy and moderation choices.

Likely Impacts on My Career

Both technologies fit my goal of building software and games. I expect AI tools to be part of my development workflow, so I need to understand their suggestions, test changes, and protect user data. Clearspace gave me practice with validation, regression testing, and explaining technical limits. I want to use AI assistance while continuing to develop those skills.

XR interests me because I build VRChat worlds as a hobby, and the C# I use in Clearspace carries over to Unity. Working with XR would push me to learn more about 3D interaction and performance. Comparing software and game development roles will help me decide which skills to develop next.
