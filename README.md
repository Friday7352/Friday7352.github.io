# CS 499 ePortfolio

Payton Castle's capstone ePortfolio for the B.S. in Computer Science at Southern New Hampshire University.

**Live site:** https://friday7352.github.io/

## Start here

Open `index.html` (the live site's home page). It begins with the professional self-assessment, followed by three enhancements to one artifact, Clearspace, a Windows file manager written in C# and WPF:

| Category | Narrative page |
| --- | --- |
| Software design and engineering | `artifact-one.html` |
| Algorithms and data structures | `artifact-two.html` |
| Databases | `artifact-three.html` |

The home page also links the code review video and two journals.

## Folder guide

- `assets/artifacts/` - original and enhanced source archives, with `manifest.json` listing checksums
- `assets/software-design/`, `assets/algorithms/`, `assets/databases/` - Word narratives, implementation notes, and test reports
- `assets/self-assessment/` - the professional self-assessment (Word)
- `assets/journals/` - the Module 3 and Module 5 journals

The Clearspace source repository is at https://github.com/Friday7352/Clearspace.
